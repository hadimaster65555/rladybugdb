# Convert an lb_result to a tbl_graph (tidygraph)

Convert an lb_result to a tbl_graph (tidygraph)

## Usage

``` r
as_tbl_graph(x, ...)
```

## Arguments

- x:

  An `lb_result` object.

- ...:

  Unused.

## Value

A
[`tidygraph::tbl_graph()`](https://tidygraph.data-imaginist.com/reference/tbl_graph.html)
object.
